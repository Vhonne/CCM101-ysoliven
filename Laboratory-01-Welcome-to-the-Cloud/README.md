# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to the Linux environment and basic cloud computing concepts. I used the KillerCoda Playground to access an Ubuntu Linux environment and created a GitHub repository for my Cloud Computing Portfolio.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed the Ubuntu 24.04 Linux environment using KillerCoda.
- Created and used a Linux user account.
- Checked the current username, working directory, and hostname.
- Gathered information about the Linux distribution, kernel, CPU, memory, and disk space.
- Created and viewed a Markdown file containing system information.
- Created directories and files using Linux commands.
- Created and organized a Cloud Computing Portfolio on GitHub.

## Linux Commands Used

- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the hostname.
- `uname -r` – displays the kernel version.
- `lscpu` – displays CPU information.
- `free -h` – displays memory information.
- `df -h` – displays disk space information.
- `ls` – lists files and directories.
- `mkdir` – creates directories.
- `cd` – changes the current directory.
- `cat` – displays the contents of a file.
- `echo` – writes text to a file.

## Skills Learned

Through this activity, I learned how to navigate a Linux environment, use basic Linux commands, gather system information, create and manage files and directories, and document technical work using Markdown. I also learned how to organize a GitHub repository for my Cloud Computing activities.
